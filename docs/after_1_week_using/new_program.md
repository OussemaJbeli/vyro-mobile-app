# Weekly Schedule — Monday → Sunday

Because the program is a **4-day repeating cycle**, the calendar week does not have to restart the program every Monday.

For a Monday-start week, use:

| Day           | Training                          |
| ------------- | --------------------------------- |
| **Monday**    | 🔴 Day 1 — Push + Real Speed      |
| **Tuesday**   | 🟠 Day 2 — Pull + Speed Endurance |
| **Wednesday** | 🟡 Day 3 — Legs + Easy Run        |
| **Thursday**  | 🟢 Day 4 — Complete Rest          |
| **Friday**    | 🔴 Day 1 — Push + Real Speed      |
| **Saturday**  | 🟠 Day 2 — Pull + Speed Endurance |
| **Sunday**    | 🟡 Day 3 — Legs + Easy Run        |

Then the following Monday becomes:

**Day 4 — Complete Rest**

and the cycle continues.

### Calendar pattern

```text
MON     TUE       WED        THU        FRI       SAT       SUN
PUSH    PULL      LEGS       REST       PUSH      PULL      LEGS
+       +         +                     +         +         +
SPEED   SPEED     EASY                  SPEED     SPEED     EASY
```

This means you get:

**2× Push + Speed**
**2× Pull + Speed Endurance**
**2× Legs + Easy Run**
**1× Complete Rest**

during a Monday–Sunday week.

The rest day moves through the calendar because the program is based on a **4-day cycle**, not a fixed 7-day split.
